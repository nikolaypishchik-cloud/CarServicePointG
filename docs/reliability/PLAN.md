# CarServicePG 2.1.2 — постійний план надійності та готовності до випуску
Ідентифікатор: REL-212. Створено: 2026-11-05. Статус: ВИКОНУЄТЬСЯ.
План погоджений користувачем для поетапного виконання між сесіями. Це єдине джерело плану; не створювати його заново.
Поточний стан: [STATUS.md](STATUS.md). Сценарії: [MATRIX.csv](MATRIX.csv).

## Правила продовження
1. Перед роботою прочитати PLAN.md і STATUS.md, перевірити ліміт за чинними інструкціями користувача.
2. Перевірити фактичні журнали та версію/хеш збірки. Не вважати старий PASS доказом для зміненого EXE.
3. Обрати незавершений пункт; можна переключатися між незалежними етапами. Залежні етапи виконувати після передумов.
4. Після кожної сесії оновити STATUS.md: зроблено, докази, відкриті дефекти, наступна дія, запущені процеси та їх журнали.
5. Для тесту зберігати ID, передумови, дані, кроки, незалежне очікування, фактичний результат, середовище, час, хеш і докази.
6. Статуси: TODO, IN_PROGRESS, PASS, FAIL, BLOCKED, NOT_RUN, RETEST_REQUIRED. PASS лише за доказами. Виправлення коду без повторного тесту не закриває дефект.
7. Після змін визначати залежні перевірки й позначати RETEST_REQUIRED. Історію не стирати; суперечливі результати зберігати.
8. Перерва чи інша задача не означає завершення плану. Не запускати автоматизації й не обіцяти роботу поза активною сесією.
9. Завершення можливе лише після всіх обов'язкових перевірок фінальної збірки та звіту з залишковими обмеженнями. Абсолютну 100% безвідмовність не обіцяти.

## Незмінні умови
Тільки ізольовані копії застосунку, БД, налаштувань і вкладень. Перевірити всі шляхи запису.
Реальні платежі, замовлення та повідомлення заборонені в тестах; використовувати тестові відповіді.
Робочі дані не змінювати. Аварійно завершувати лише власні тестові процеси.
Гейти не послаблювати, FAIL/QCRITICAL/QFATAL/SKIP не приховувати.
Зберігати версію 2.1.2; оновлювати існуючий dist лише після відповідних перевірок і перевірки процесів; без примусового завершення робочого застосунку.
Інсталятор на робочому ПК без окремого дозволу не запускати.
